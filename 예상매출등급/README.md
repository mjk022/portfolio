# 서울 음식점 매출등급 예측 (2023 빅콘테스트)

> 서울시 음식점들의 매출등급(1~5등급)과 주변 환경 데이터를 분석해, 2023년 1·2월의 매출등급을 예측하고 폐업 위험이 큰 가게를 찾아낸 공모전 프로젝트입니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 언제 | 2023.08 – 2023.09 |
| 누가 | 3인 팀, 본인은 기간별·업종별 탐색적 분석(EDA) 담당 |
| 어디서 | 제11회 2023 빅콘테스트, 빅데이터플랫폼 활용 분야 (지정주제: 부동산) |
| 무엇을 | 서울시 필지(땅) 단위 음식점의 미래 매출등급 예측 |
| 왜 | 음식점 폐업률이 전체 산업의 두 배에 가까워, 위험한 가게를 미리 찾아 지원하기 위해 |
| 어떻게 | 공공데이터 9종을 추가로 결합 → 탐색적 분석 → 머신러닝 모델 7종 비교 |
| 결과 | ExtraTrees 모델로 예측 오차(MSE) 0.407 달성, 업종·지역별 위험 패턴 발견 |

## 1. 왜 시작했나

코로나 이후에도 고물가·고금리가 이어지면서 상가 공실률이 계속 오르고 있습니다. 특히 음식점은 창업이 쉬운 만큼 폐업도 많아서, 2019년 기준 폐업률이 21.5%로 전체 산업 평균(11.5%)의 두 배 가까이 됩니다.

가게의 매출등급을 미리 예측할 수 있다면, 매출이 떨어질 것으로 예상되는 가게를 먼저 지원하거나, 창업하려는 사람이 입지를 고를 때 참고 자료로 쓸 수 있습니다.

## 2. 무엇을 했나

```mermaid
flowchart LR
    A[대회 제공 데이터<br/>가게별 매출등급] --> C[데이터 결합]
    B[공공데이터 9종<br/>유동인구·지하철역·젠트리피케이션 등] --> C
    C --> D[전처리<br/>빈 값 채우기·정규화]
    D --> E[탐색적 분석<br/>업종별·지역별·기간별]
    D --> F[모델 7종 비교]
    F --> G[ExtraTrees 선택 및 튜닝]
    G --> H[2023년 1·2월<br/>매출등급 예측]
```

**① 주변 환경 데이터 추가**
대회에서 준 데이터는 "어느 땅의 어떤 업종 가게가 몇 등급인지"뿐이었습니다. 하지만 매출은 가게 주변에 사람이 얼마나 다니는지, 지하철역이 가까운지 등에 크게 좌우됩니다. 그래서 공공데이터를 추가로 모아 결합했습니다.

| 추가 데이터 | 의미 | 출처 |
|---|---|---|
| 필지 기초데이터 | 땅 면적, 위치(위도·경도) | 부동산 빅데이터 플랫폼 |
| 젠트리피케이션 위험지수 | 임대료 상승으로 기존 상인이 밀려날 위험 | 부동산 빅데이터 플랫폼 |
| 배후지 인구당 상가면적 | 주변 인구에 비해 상가가 얼마나 많은지 | 부동산 빅데이터 플랫폼 |
| SNS 노출·부동산 거래 대비 유동인구 | 상권의 활기 | 부동산 빅데이터 플랫폼 |
| 지하철역 위치 | 반경 800m 안의 역 개수 | 서울 열린데이터광장 |
| 상권변화지표, 생활인구 | 상권이 성장 중인지, 주변에 사는 사람 수 | 서울 열린데이터광장 |

**② 전처리**
면적처럼 값의 차이가 지나치게 큰 변수는 로그 변환으로 분포를 고르게 만들었습니다. 비어 있는 값은 비슷한 이웃 데이터의 값으로 채웠고(KNN Imputer), 위치 정보가 빠진 경우에는 땅 번호를 주소로 바꾼 뒤 지도 API로 좌표를 직접 찾았습니다.

**③ 탐색적 분석: 기간별·업종별 (본인 담당, `기간별EDA.ipynb`)**
먼저 월별로 등급 분포를 봤지만 달마다 거의 차이가 없었습니다. 그래서 시간보다는 **가게 단위**로 보는 것이 의미 있다고 판단했습니다. 같은 땅의 같은 업종을 하나의 가게로 보고, 영업한 달들의 평균 등급을 구해 "우수 가게(평균 2등급 이내)"와 "위기 가게(평균 4등급 이상)"를 나눴습니다. 업종마다 가게 수가 크게 달라서 개수 대신 업종별 비율로 비교했습니다.

**④ 모델 비교 (팀)**
머신러닝 모델 7종을 같은 데이터로 학습해, 실제 등급과 예측 등급의 차이(MSE, 낮을수록 좋음)를 비교했습니다.

## 3. 결과

**탐색적 분석에서 발견한 것**

| 분석 | 발견 | 해석 |
|---|---|---|
| 우수 가게 | 패스트푸드 비율이 가장 높고, 주점이 가장 낮음 | 패스트푸드는 운영 매뉴얼이 통일되어 품질이 고름 |
| 위기 가게 | 기타 외국식이 가장 많음 | 가게마다 콘셉트와 맛 차이가 커서 성패가 갈림 |
| 1년 미만 가게 | 아이스크림/빙수가 1등급과 5등급 모두 많음 | 계절을 크게 타서 매출이 안정적이지 않음 |
| 지역별 (팀) | 강남·서초구는 꾸준히 높고, 도봉·강북·성북·동대문·중랑·은평구는 낮음 | 지역 맞춤 지원이 필요 |

**모델 비교**

| 모델 | 예측 오차 (MSE) |
|---|---|
| GradientBoosting | 1.18 |
| LightGBM | 1.11 |
| XGBoost | 1.06 |
| DecisionTree | 0.81 |
| RandomForest | 0.45 |
| ExtraTrees (기본 설정) | 0.434 |
| **ExtraTrees (최적화)** | **0.407** |

가장 오차가 작은 ExtraTrees를 최종 모델로 선택해 2023년 1·2월 매출등급을 예측했습니다. 이 결과를 바탕으로 등급이 크게 떨어질 것으로 예상되는 가게를 미리 지원하는 방안, 지역별 상권 대시보드, 저등급 매장을 위한 SNS 마케팅 교육 등을 제안했습니다.

## 4. 배운 점

주어진 데이터만으로는 설명할 수 없는 부분을 공공데이터로 보완하는 과정에서, 문제에 맞는 데이터를 찾아 붙이는 것이 모델 선택만큼 중요하다는 것을 배웠습니다. 또 단순한 개수 비교가 아니라 비율로 정규화해야 업종 간 공정한 비교가 가능하다는 점도 분석하며 체감했습니다.
