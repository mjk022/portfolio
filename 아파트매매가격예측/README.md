# 생성 AI 기반 뉴스 감성 분석과 부동산 가격 예측

**생성 AI기반 뉴스 감성 분석과 부동산 가격 예측: LSTM과 VAR모델의 적용**
김수아, 권미주, 김현희 · 정보처리학회논문지 (한국정보처리학회), 2024
ACK 2023 발표 논문 「생성 AI 기반 뉴스 기사 심리지수를 활용한 부동산 가격 예측 모델」을 확장한 논문

- 논문 정보: [DCollection](https://dcollection.sogang.ac.kr/dcollection/srch/srchDetail/000000081272)

## 개요

뉴스 기사의 감성을 수치화한 **뉴스 감성 지수(NSI)** 를 거시경제 변수와 함께 넣어 전국 아파트 매매가격지수를 예측했습니다.

1. **데이터 수집**: 2019.01 ~ 2023.03 월별 아파트 매매가격지수(KB 부동산 데이터 허브), 기준금리, 명목 GDP, 대출금리, 아파트 매매거래량. 네이버 부동산 뉴스 약 30,600건 크롤링
2. **NSI 산출**: KoBART로 기사 요약 → ChatGPT로 긍정(1)/중립(0)/부정(-1) 라벨링 (미분류·중립은 사람이 검수) → 월별 합계
3. **예측 모델**: Multi-head attention LSTM, VAR. 학습 2019.01 ~ 2022.12, 테스트 2023.01 ~ 03

## 결과 (RMSE)

| 모델 | 1개월 | 2개월 | 3개월 |
|---|---|---|---|
| LSTM (NSI 제외) | 0.60 | 0.872 | 1.117 |
| **LSTM (NSI 포함)** | **0.40** | **0.724** | **1.03** |
| VAR (NSI 제외) | 1.6484 | 0.6254 | 0.9220 |
| **VAR (NSI 포함)** | **1.1315** | **0.3413** | 1.6227 |

NSI를 넣으면 LSTM은 모든 기간에서, VAR는 1·2개월 단기 예측에서 오차가 줄었습니다.
