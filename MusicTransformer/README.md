# Music Transformer로 "쇼팽이 연주하는 캐롤" 만들기

> 쇼팽의 피아노곡으로 학습한 AI 작곡 모델에게 캐롤의 첫 소절을 들려주고, 그 뒤를 쇼팽 스타일로 이어서 연주하게 만든 프로젝트입니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 언제 | 2025.11 – 2025.12 |
| 누가 | 대학원 G조 5인 팀 (권미주 외 4명) |
| 어디서 | 대학원 「인공지능의 원리와 응용」 수업 팀 과제 |
| 무엇을 | Music Transformer 모델 분석 및 "작곡가 스타일 캐롤" 생성 |
| 왜 | 텍스트용 Transformer가 음악에서는 어떻게 달라지는지 이해하고, 직접 응용해 보기 위해 |
| 어떻게 | Keras 공식 예제를 기반으로, 쇼팽 곡만 골라 학습한 뒤 캐롤을 프롬프트로 입력 |
| 결과 | 캐롤 멜로디에 쇼팽 특유의 화성이 섞인 피아노 곡 생성 (`samples/` 폴더) |

## 1. 왜 시작했나

ChatGPT 같은 언어 모델은 "다음에 올 단어"를 예측하며 문장을 만듭니다. 음악도 음표가 순서대로 이어진 것이니, 같은 원리로 "다음에 올 음"을 예측하면 작곡을 할 수 있습니다. 이 아이디어를 구현한 것이 Google의 **Music Transformer**입니다.

수업 과제로 이 모델을 분석하면서, 단순히 예제를 돌려보는 것을 넘어 **"특정 작곡가의 스타일을 배운 모델에게 익숙한 노래를 들려주면 어떻게 이어서 연주할까?"** 라는 질문을 직접 실험해 보기로 했습니다. 발표 시기가 12월이라 소재로 캐롤을 골랐습니다.

## 2. 핵심 개념 쉽게 이해하기

**음악을 숫자로 바꾸기 (토큰화)**
MIDI 파일은 악보 대신 "어떤 건반을 눌렀다", "얼마나 세게", "몇 밀리초 뒤에", "건반을 뗐다" 같은 연주 기록을 담은 파일입니다. 이 기록 하나하나를 숫자(토큰)로 바꾸면, 문장의 단어처럼 모델이 읽을 수 있습니다.

```
건반 60 누름 → 세기 70 → 20ms 대기 → 건반 60 뗌
      ↓
   [55, 77, 61, 12, 90]
```

**Music Transformer가 일반 Transformer와 다른 점**

| 구분 | 일반 Transformer (번역 등) | Music Transformer |
|---|---|---|
| 구조 | 원문을 읽는 부분 + 번역문을 쓰는 부분 | **쓰는 부분(Decoder)만** 사용. 앞에 나온 음을 보고 다음 음만 이어 붙이면 되기 때문 |
| 위치 정보 | "몇 번째 단어인가" (절대 위치) | **"앞 음과 얼마나 떨어져 있는가"** (상대 위치) |

음악에서는 같은 멜로디가 다른 위치에서 반복되는 경우가 많습니다. 그래서 "3번째 음"이라는 절대 위치보다 "두 음 사이 간격"이라는 상대 위치가 더 중요하고, 이것이 Music Transformer의 핵심인 **상대 위치 어텐션**입니다. 이를 메모리를 적게 쓰며 계산하기 위해 행렬을 비스듬히 밀어 정렬하는 **Skewing** 기법을 사용합니다.

## 3. 무엇을 했나

```mermaid
flowchart LR
    A[MAESTRO<br/>피아노 연주 데이터] --> B[쇼팽 곡만 선별]
    B --> C[MIDI → 숫자 토큰]
    C --> D[Music Transformer 학습]
    E[캐롤 MIDI] --> F[첫 부분을 토큰으로]
    D --> G[다음 음 예측을<br/>1024번 반복]
    F --> G
    G --> H[쇼팽풍 캐롤 MIDI]
```

**① 기본 예제 재현**
Keras 공식 예제를 그대로 실행해, 국제 피아노 콩쿠르 연주 기록인 MAESTRO 데이터셋 전체로 학습한 모델이 피아노 곡을 만드는 것을 확인했습니다.

**② 베토벤으로 첫 시도 → 실패**
베토벤 곡만 골라 추가 학습한 뒤 캐롤 앞부분을 들려줬습니다. 그런데 베토벤 특유의 무겁고 극적인 연주가 이어져, 캐롤의 밝은 분위기와 전혀 어울리지 않았습니다.

**③ 쇼팽으로 변경 → 개선**
서정적인 선율이 많은 쇼팽으로 작곡가를 바꾸고, 학습 횟수를 100회로 늘렸습니다. 캐롤 한 곡을 시작 부분(seed)으로 주자 캐롤의 멜로디 분위기를 유지하면서 쇼팽 특유의 화성이 더해진 결과가 나왔습니다.

**④ 생성 방식 다듬기**
마지막 1024개 토큰을 보고 가장 확률이 높은 다음 토큰을 고르는 과정을 1024번 반복하도록 정리했습니다.

## 4. 결과

| 시도 | 결과 |
|---|---|
| 기본 예제 | 일반적인 피아노 곡 생성 |
| 베토벤 스타일 | 캐롤과 어울리지 않는 무거운 연주 |
| **쇼팽 스타일** | **캐롤 멜로디 + 쇼팽의 화성 감각** |

`samples/` 폴더에 쇼팽 곡을 시작 부분으로 생성한 결과 5곡을 넣어 두었습니다. MIDI 재생 프로그램이나 온라인 MIDI 플레이어로 들어볼 수 있습니다.

## 5. 배운 점

같은 모델 구조라도 **어떤 데이터로 학습시키느냐**에 따라 결과의 성격이 완전히 달라진다는 것을 직접 확인했습니다. 또 텍스트용으로 알려진 Transformer가 음악이라는 다른 영역에 맞게 위치 정보 처리 방식을 바꾼 과정을 분석하면서, 모델 구조가 데이터의 특성에서 출발한다는 점을 이해할 수 있었습니다.
