# Portfolio — 권미주

데이터 분석, 머신러닝, 딥러닝 프로젝트를 모아 둔 저장소입니다.

정보통계학을 전공하며 공모전, 학회, 캡스톤 디자인에서 실제 데이터를 다뤘고,<br>
대학원 수업에서는 생성 모델을 공부했습니다.<br>
각 프로젝트는 데이터를 직접 수집하고 정리하는 단계부터 모델을 만들고<br>
결과를 해석하는 단계까지 분석의 전 과정을 담고 있습니다.

## 대표 프로젝트

**[뉴스 감성으로 아파트 가격 예측하기](./아파트매매가격예측)** — 학술지 게재 논문

부동산 뉴스 30,600건을 생성 AI로 분석해<br>
시장 분위기를 숫자(뉴스 감성 지수)로 만들고, 이를 아파트 가격 예측 모델에 추가했습니다.<br>
감성 지수를 넣은 LSTM 모델은 1개월 예측 오차가 0.60에서 0.40으로 줄었습니다.<br>
이 연구는 정보처리학회논문지(2024)에 게재되었습니다.<br>
예측 결과는 [웹사이트](https://mjk022.github.io/portfolio/)에서 직접 확인할 수 있습니다.
